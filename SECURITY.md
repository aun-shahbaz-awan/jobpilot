# Security

JobPilot stores your profile, CV and API keys in your own database. If you find a security issue, please don't open a public issue. Report it privately through GitHub's [private vulnerability reporting](https://github.com/aun-shahbaz-awan/jobpilot/security/advisories/new).

When you deploy JobPilot, set `APP_PASSWORD` so the site isn't open to anyone with the link, and prefer environment variables over saving API keys in Settings.
